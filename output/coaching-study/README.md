対局は実際のYaneuraOuによるローカル対局。例文はその保存局面を入力にセッション内のモデルが作り、根拠を確認したもの。ブラウザー内の小型モデル、Jev、音声生成の実行結果ではない。

`randomized/` がランダム開始12手とSkillLevelを使った本調査。直下の対局・例文は固定開始列のパイロットとして分離している。各ディレクトリに完全な `games.json`、選択局面の `facts.json`、再生用 `.usi`、解析条件、検証結果を保存した。

既存アプリとレッスンの実装は変更していない。設計用の未充填スロットと、実局面に対応する例文を混同しない。
