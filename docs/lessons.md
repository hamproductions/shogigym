# Lessons: sources and build

Every lesson in 学ぶ (Learn) is generated. Do not edit `src/data/lessons/` by hand; change the source data or the converter and rebuild.

```sh
bun run lessons   # scripts/lessons/build.ts -> src/data/lessons/*.json, then scripts/validate-curriculum.mjs
```

## How a lesson is built

`scripts/lessons/build.ts` turns each topic into one catalog entry (`src/data/lessons/<topic>.json`) whose chapters are standard courses (`RawCourse`, the same format as the joseki courses):

- **Side.** A lesson is written for one side: the side its figures are drawn from (most figures shown from 後手 → 後手). Every chapter uses that side.
- **Chapters.** Figures connected by moves the article states form one chapter; the explanation of each figure is the comment on its position, and its arrows/highlights/partial illustration are kept on `node.figures`. A figure the text does not connect by moves starts a new chapter. A chapter that resumes from the position where another ended is joined onto it.
- **Variations.** A figure introduced as 「図Xから…」 (for example 図2-4′ "▲7七角に代えて▲6六歩と指した場合") becomes a variation branch at 図X, using the moves the text names (matched move by move, including 成/不成). Unnamed or ambiguous connections are never invented.
- **Notes.** Every adjustment is written into the lesson text: moves the article omits or misstates, pieces placed only because the figure shows them, hands the figure does not show.

`scripts/validate-curriculum.mjs` replays every chapter and variation, rejects illegal positions, and requires an explanation and an image source on every figure.

## In the app

The library lists lessons by category; under 定跡 the learner picks a strategy and sees that strategy's lessons with its matchup courses. Opening a lesson starts the guide: the panel shows the current figure's explanation (or the figure the moves are heading to), → plays the next move in source order including variations, ← takes one back, and the end shows the check question, a quiz over the lesson's moves and the next lesson. Each lesson links to its article.
